# The Desk — review app (Phase 3)

The human approval gate, designed in Claude Design and imported here. A calm,
paper-like queue where Jordan reads one job at a time — parsed facts, fit score
+ why, tailored resume diff, and a cover letter in his voice — then Approve /
Ignore / Save. The AI does the grind; he keeps the voice and the final click.

## Files
- `The Desk - Triage.dc.html` — the app (a Claude Design `<x-dc>` component).
- `support.js` — Claude Design's runtime. It self-boots React + ReactDOM from
  unpkg, so the app runs in any browser with internet — no build step.
- `desk-data.js` — real job data hook. Committed as `window.__DESK_DATA = null`,
  which makes the app fall back to its built-in sample jobs (the full designed
  experience). `cli export` overwrites it with the engine's real shortlist.

## Run it
Open `The Desk - Triage.dc.html` directly in a browser, or serve the folder:
```bash
python3 -m http.server 8753            # from this directory
# → http://127.0.0.1:8753/The%20Desk%20-%20Triage.dc.html
```

## Feed it real jobs
From the project root, after a `sweep` + `match`:
```bash
python3 -m apply_assistant.cli export   # writes review-app/desk-data.js
```
Reload the page and the queue shows the engine's real strong/stretch matches —
real facts, scores, "why this fits you", and gaps. Cover letter and resume diff
are honest placeholders until the Phase-2 tailoring layer is built; everything
else is live. To go back to the sample experience, set `window.__DESK_DATA = null`.

## Note
The component is generated by Claude Design. The only local edits are a tiny
`realOrSeed()` / `seedHistory()` hook so it prefers `window.__DESK_DATA` when
present — keep those if you re-import an updated design.
